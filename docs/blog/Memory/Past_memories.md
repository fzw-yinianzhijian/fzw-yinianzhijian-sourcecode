装载一些早些时候的整理。

好像从很早开始我就是一个喜欢写东西的人，可惜文字零零散散的，也没有个规整的体系。

小时候我还真写过日记欸，我记得之前会有个小红本本啥的，缩在一个小盒子里，里面写了自己的想法吧，有一段是我还是大队长，然后上课顶撞音乐老师，被留下来了，印象超级深刻。

前段时间也还在尝试用纸写日记，可惜效率太低，且那个小本本我也不会随身带啊。

我从来不是一个会收拾整理的人，对于文字和图片也是这样，他会散乱的排布在四处，我知道他在，我便很安心了。

我把他放在这里就像是给自己一个机会，让自己在旧日的海洋中翻翻找找。

若有看到精彩有趣的或者让自己会心一笑的，那我捡拾起来拍拍灰，放在桌面上，算是踏在时间轴上的一个脚印。

总觉得自己过去是小朋友，哈哈现在也还是。
